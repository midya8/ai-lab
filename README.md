# ai-lab

Midya's AI lab: small, tested, runnable AI projects.

| Project | Pitch |
|---|---|
| [PartsLab](https://github.com/midya8/partslab) | Manual NMF, exact fixed-basis objective bounds and [one-pixel fixed-face NNLS response](https://midya8.github.io/partslab/face.html). Fraction/BigInt affine KKT intervals, endpoint ties, singleton and nonuniqueness controls; 38 Python/eleven Node tests, 200 tiny face oracles, 54 native/Worker witnesses and 10,368 pixel checks. Ten modules/ten commands, original six fits/data/scores unchanged. Stronger signed PCA/SVD controls still win; joint fits still exhaust their stationarity budget. Not unique semantic parts, a full path, robustness or joint-NMF optimality. |
| [MixtureLab](https://github.com/midya8/mixturelab) | Manual constrained Gaussian-mixture EM and [frozen observed-coordinate conditionals](https://midya8.github.io/mixturelab/conditional.html). Marginal evidence, Schur complements and within/between covariance. 45 Python/eleven Node tests; 5,696 original cases, 160 native/scalar-JS references and 160 UI cases. Mean-in-a-gap and increasing-variance controls. Twelve modules/nine commands; original fits/scores unchanged. Analytical masks, not real missingness, causal inference or calibrated intervals. |
| [DenoiseLab](https://github.com/midya8/denoiselab) | Manual denoising, neural/PCA response, scalar paths and [two-pixel exact retrieval cells](https://midya8.github.io/denoiselab/plane.html). Fraction/BigInt area/edge/point/empty witnesses and source-matched supporting-halfplane/infeasibility proofs. 52 Python/fourteen Node tests; 238 independently enumerated cells, 2,110 oracle queries, 160 browser queries and 30,720 canvas colors; ten modules/nine commands. Original winning controls/models/scores unchanged. Fixed two-coordinate slice, not general robustness, causal recourse, uncertainty, new accuracy or binary64 tie equivalence. |
| [TagLab](https://github.com/midya8/taglab) | Manual CRF learning and 327-state optimization replay; fixed-score label events, auditable joint sampling and [nonlocal exact-count inference](https://midya8.github.io/taglab/counts.html). Count-state witnesses and an independent-node control distinguish exact counts from expectations. 43 Python/20 Node tests; 5,895 browser states/queries; eleven modules/nine commands. Selected chain wins NLL but loses Viterbi token errors (66/164 versus same-feature control 56/164). Synthetic illustration, not NLP validation, causal intervention or calibrated confidence. Original fits/budgets unchanged; finite-precision, PRNG and tie limits explicit. |
| [SpectralLab](https://github.com/midya8/spectrallab) | Manual normalized graph clustering, complete degree-response derivatives and basis-invariant projector sensitivity. 33 Python/nine Node tests; 1,728 original point states plus 168 sensitivity states. [Graph inspector](https://midya8.github.io/spectrallab/), [finite-refit sensitivity](https://midya8.github.io/spectrallab/sensitivity.html). Tied rounding and refused boundaries stay visible. Original synthetic full-data illustration, not prediction, a label gradient or exact discrete optimization. |
| [ForestLab](https://github.com/midya8/forestlab) | Manual CART forests, exact Gini ordering, bootstrap/OOB and joint permutation witnesses. New [leaf-collision geometry](https://midya8.github.io/forestlab/proximity.html): exact Gram sums of squares, jointly-OOB denominators and undefined pairs, an exact negative OOB quadratic control. 39 Python/12 Node-Chrome tests, 512 independent partition controls and 13,824 heatmap colors; ten-module/ten-command reproduction. Original stronger 5NN and all scores stay unchanged. Model geometry, not semantic similarity, calibrated confidence or causal influence. |
| [RatingLab](https://github.com/midya8/ratinglab) | Observed-only ALS, strong winning bias control and finite conditional ridge edit/deletion responses with saved-vs-re-solved baselines, leverage and independent direct refits. 30 Python/nine Node tests. [Conditional response inspector](https://midya8.github.io/ratinglab/influence.html). Frozen-factor response, not full retraining, unlearning or causal influence. |
| [MarginLab](https://github.com/midya8/marginlab) | Manual linear/RBF dual SVM and exact represented-linear weak-duality proofs after equality repair; independent Fraction/BigInt readers and separate source matching. 29 Python/nine Node tests. [Live proof inspector](https://midya8.github.io/marginlab/certificate.html). Historical educational data, not clinical validation or authentication. |
| [rag-evals](rag-evals) | From-scratch BM25, LSA and RRF-hybrid RAG retrieval with chunking and Recall/MRR/nDCG evaluation harness |
| [agentkit](agentkit) | Dependency-free LLM agent runner: tool-calling loop, bounded steps, loop detection, dry-run, JSON trace — 46 tests |
| [ragkit](ragkit) | Local RAG over your own docs: chunking, TF-IDF/BM25 retrieval, answers with citations, eval — 59 tests |
| [evalkit](evalkit) | LLM eval harness: golden sets, scorers, regression compare, Markdown/JSON reports — 36 tests |
| [guardkit](guardkit) | Runtime guardrails for LLM pipelines: injection scoring, PII/secret redaction, policy file, audit log, adversarial eval — 62 tests |
| [tiny-transformer](tiny-transformer) | GPT from scratch in pure NumPy with hand-written backprop (gradient-checked), trainer and sampler; RoPE option vs learned positions (89 tests) |
| [llm-eval-harness](llm-eval-harness) | Pluggable LLM eval harness with scorers, prompt suites and a CI regression gate |
| [agentflow](agentflow) | Multi-agent orchestration framework: tool-using agents, task DAG, parallel runs, retries, supervisor routing, shared memory, circuit breakers, run on llm-router with per-agent cost reports, crash-safe run log with fingerprint-based resume — 50 tests |
| [logsentry](logsentry) | Log anomaly detection: template mining, robust volume spikes, error bursts, new-pattern alerts, per-template spikes, streaming mode, Prometheus exporter, webhook alerts |
| [ticket-triage](ticket-triage) | Support-ticket triage classifier from scratch: TF-IDF + softmax regression with confidence-based escalation |
| [lora-lab](lora-lab) | LoRA from scratch in NumPy: manual backprop, gradcheck, merge/unmerge, rank sweep, plus adapters on the tiny-transformer GPT attention (3.7% of weights cuts new-domain NLL 5.69 → 1.50), plus an adapter hub that swaps, blends, routes and SVD-composes adapters, plus QLoRA-style adapters on an int8/NF4/int4-quantized frozen base (4.3x smaller model, same adapter quality; 50 tests) |
| [llm-router](llm-router) | Cost/latency-aware LLM router: complexity scoring, 4 strategies, fallback chains, circuit breakers, exact + semantic cache, budget guardrails, cascade, outage simulator — 53 tests |
| [promptlab](promptlab) | Prompt versioning + paired A/B testing (exact McNemar, Wilson/bootstrap CIs) + baseline regression gate + GitHub Action for CI + LLM-as-judge checks with judge calibration (agreement, Cohen's kappa, Spearman, leniency bias) — 64 tests |
| [docqa](docqa) | Grounded document Q&A: verbatim cited sentences, coverage-based abstention ("I don't know"), synonym-aware paraphrase matching, corpus-grounded typo correction, HTTP service with answer cache + Prometheus metrics — 64 tests |

Notes on overlap: `rag-evals` is retrieval-only evaluation; `ragkit` adds answering with citations on top of retrieval. `evalkit` is a general prompt/model eval harness; `rag-evals` is RAG-specific, and `llm-eval-harness` is the pluggable-backend variant. `guardkit` is runtime input/output guardrails; `promptguard` (separate repo) is the static file linter for prompt files.

Each project is self-contained with its own README, tests, and CI. All run offline with no API keys — a stub provider is used for demos and tests; a real LLM is opt-in via an environment variable.

See [ROADMAP.md](ROADMAP.md) for what's next.
