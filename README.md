# ai-lab

Midya's AI lab: small, tested, runnable AI projects.

| Project | Pitch |
|---|---|
| [PartsLab](https://github.com/midya8/partslab) | Manual NMF, exact fixed-basis objective bounds and [one-pixel fixed-face NNLS response](https://midya8.github.io/partslab/face.html). Fraction/BigInt affine KKT intervals, endpoint ties, singleton and nonuniqueness controls; 38 Python/eleven Node tests, 200 tiny face oracles, 54 native/Worker witnesses and 10,368 pixel checks. Ten modules/ten commands, original six fits/data/scores unchanged. Stronger signed PCA/SVD controls still win; joint fits still exhaust their stationarity budget. Not unique semantic parts, a full path, robustness or joint-NMF optimality. |
| [MixtureLab](https://github.com/midya8/mixturelab) | Manual constrained Gaussian-mixture EM and [frozen observed-coordinate conditionals](https://midya8.github.io/mixturelab/conditional.html). Marginal evidence, Schur complements and within/between covariance. 45 Python/eleven Node tests; 5,696 original cases, 160 native/scalar-JS references and 160 UI cases. Mean-in-a-gap and increasing-variance controls. Twelve modules/nine commands; original fits/scores unchanged. Analytical masks, not real missingness, causal inference or calibrated intervals. |
| [DenoiseLab](https://github.com/midya8/denoiselab) | Manual denoising, neural/PCA response, scalar paths and [two-pixel exact retrieval cells](https://midya8.github.io/denoiselab/plane.html). Fraction/BigInt area/edge/point/empty witnesses and source-matched supporting-halfplane/infeasibility proofs. 52 Python/fourteen Node tests; 238 independently enumerated cells, 2,110 oracle queries, 160 browser queries and 30,720 canvas colors; ten modules/nine commands. Original winning controls/models/scores unchanged. Fixed two-coordinate slice, not general robustness, causal recourse, uncertainty, new accuracy or binary64 tie equivalence. |
| [TagLab](https://github.com/midya8/taglab) | Manual CRF learning and 327-state optimization replay; fixed-score label events, auditable joint sampling and [nonlocal exact-count inference](https://midya8.github.io/taglab/counts.html). Count-state witnesses and an independent-node control distinguish exact counts from expectations. 43 Python/20 Node tests; 5,895 browser states/queries; eleven modules/nine commands. Selected chain wins NLL but loses Viterbi token errors (66/164 versus same-feature control 56/164). Synthetic illustration, not NLP validation, causal intervention or calibrated confidence. Original fits/budgets unchanged; finite-precision, PRNG and tie limits explicit. |
| [SpectralLab](https://github.com/midya8/spectrallab) | Manual normalized graph clustering, complete degree-response derivatives and basis-invariant projector sensitivity. 33 Python/nine Node tests; 1,728 original point states plus 168 sensitivity states. Original synthetic full-data illustration, not prediction, a label gradient or exact discrete optimization. |

Original stronger 5NN and all scores stay unchanged. Model geometry, not semantic similarity, calibrated confidence or causal influence. |

Original models/scores unchanged. Frozen-block algebra, not full retraining, cross-validation, unlearning, causal influence or uncertainty. |
| [MarginLab](https://github.com/midya8/marginlab) | Manual SVM and repaired exact training-objective proofs, now [exact input boxes](https://midya8.github.io/marginlab/box.html): attained score bounds, both corners, tie-aware labels and source consistency.36Python/15Node-Chrome tests,120exhaustive corner cases,256direct dual endpoint sums,128full responses,11modules. Synthetic boxes, not clinical tolerances, plausible interventions, RBF, floating-inference safety or authentication. |

| [reviewkit](reviewkit) | PR code-review bot: diff parser with line tracking, 21 AST/tokenizer-aware rules (eval, shell=True, SQL injection, secrets that are never echoed, `torch.load`, mutable defaults, missing timeouts...), optional LLM pass whose replies are validated against the diff (no hallucinated lines, no pings, severity capped), idempotent inline posting, GitHub Action; scored on a dev set (1.00/1.00) and a held-out set (first run precision 0.76 / recall 0.67, reported) — 73 tests |
| [codesearch](codesearch) | Semantic code search for Python repos: AST chunking, identifier-aware terms, BM25F over name/doc/signature/body/path fields, NumPy LSA, exact-symbol pinning, incremental SHA-256 index, query-by-example and duplicate-function finder; scored on two labelled query sets (BM25F MRR 0.70 dev / 0.59 held-out vs 0.25 / 0.12 for grep-like name matching — LSA and hybrid fusion did not help, reported) — 62 tests |
| [datadoctor](datadoctor) | Dataset doctor: confident-learning label-error detection (confident joint, noise matrix, 5 pruning rules, quality scores) on cross-validated probabilities from any model, plus exact/near/conflicting duplicates, train-test leakage, MinHash text near-dupes and per-class outliers; Markdown/JSON audit CLI with a CI gate. Benchmarked on injected noise (structured noise: pruning lifts test accuracy 0.72 -> 0.87; in-sample loss is a strong baseline on easy data, reported) — 41 tests |
| [vecdb](vecdb) | Vector search from scratch: exact, IVF-Flat, IVF-PQ (residual PQ + ADC + exact re-rank) HNSW and SQ8 scalar quantisation, plus a Collection with metadata filters pushed into the search, upsert/delete and persistence; benchmarked for recall, latency and memory on 20k vectors (HNSW wins on distance evals but not Python wall-clock, PQ-only recall plateaus at 0.74, selective filters break graph walks — all reported) — 89 tests; HNSW tombstone repair |
| [microgrid](microgrid) | From-scratch reverse-mode autodiff on numpy: broadcasting, matmul, conv, SGD/Adam, gradcheck, plus transformer blocks (LayerNorm, causal attention, MiniGPT) — 24 tests |

| [promptlab](promptlab) | Prompt versioning + paired A/B testing (exact McNemar, Wilson/bootstrap CIs) + baseline regression gate + GitHub Action for CI + LLM-as-judge checks with judge calibration (agreement, Cohen's kappa, Spearman, leniency bias) + pairwise judging with a position-swap bias audit + multi-judge majority ensembles with Fleiss' kappa — 106 tests |
| [docqa](docqa) | Grounded document Q&A: verbatim cited sentences, coverage-based abstention ("I don't know"), synonym-aware paraphrase matching, corpus-grounded typo correction, HTTP service with answer cache + Prometheus metrics — 64 tests |
| [autojob](autojob) | Agentic job-application assistant: profile validation, posting parse, transparent match scoring, facts-only cover-letter drafts, review notes, JSONL application tracker, funnel analytics, interview-prep packets, follow-up reminders, tailored resume sections — never submits, drafts only — 107 tests |

Notes on overlap: `rag-evals` is retrieval-only evaluation; `ragkit` adds answering with citations on top of retrieval. `evalkit` is a general prompt/model eval harness; `rag-evals` is RAG-specific, and `llm-eval-harness` is the pluggable-backend variant. `guardkit` is runtime input/output guardrails; `promptguard` (separate repo) is the static file linter for prompt files.

Each project is self-contained with its own README, tests, and CI. All run offline with no API keys — a stub provider is used for demos and tests; a real LLM is opt-in via an environment variable.
