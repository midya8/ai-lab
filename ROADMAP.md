# Roadmap

## Done
- rag-evals: BM25 retrieval + chunking + metrics + CLI (v0.1)

- tiny-transformer: NumPy GPT with manual backprop, Adam, sampling, tests (v0.1)

- llm-eval-harness: pluggable backends, 6 scorers, suites, baseline regression gate (v0.1)

## Next
1. rag-evals: dense/hybrid retrieval (TF-IDF+SVD, RRF fusion), answer-faithfulness eval, larger benchmark
2. llm-eval-harness follow-ups: LLM-as-judge scorer, pass@k sampling, GitHub Action wrapper
3. tiny-transformer follow-ups: BPE tokenizer, KV-cache generation, LR schedule
4. multi-agent orchestration framework
5. LoRA fine-tuning pipeline
6. DevOps log anomaly detection service
7. Support-ticket triage classifier
